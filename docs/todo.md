## 真实游戏探针

- [ ] 评估 Fabric server-side mod 和 Paper plugin, 形成版本绑定, 部署方式和可观测能力对照表.
- [ ] 优先实现 Fabric server-side mod, 使用 Mixin 采集邻居更新, 计划刻, 方块事件, 活塞事件和实体阶段的精确顺序.
- [ ] 将 Paper plugin 作为轻量备选, 用于区域构建, tick 级动作, 状态探针和实际服务器验收, 不将 Bukkit/Paper API 无法观测的微时序结果标记为完整轨迹.
- [ ] 设计带协议版本的本地 CLI 会话, 一次性上传 structure, 区域, 初始化策略, 定时动作和探针, 禁止通过逐方块网络命令构建机器.
- [ ] 在服务器主线程的 `pre_tick` 执行动作, 在 `post_tick` 采样状态, 网络线程只负责请求解析和结果传输.
- [ ] 支持指定维度, 原点, 旋转, 镜像, 世界种子, feature flags 和持续加载区块.
- [ ] 实现区域锁, 导入前快照, 测试后回滚和一次性测试世界, 默认不直接修改真实存档.
- [ ] 与 GameTest oracle 共用 JSONL 探针及完整轨迹协议, 由 Rust CLI 完成差分, VCD 导出和语料归档.
- [ ] 增加跨区块, 不同方向, 绝对坐标敏感, 实验性红石, 矿车和大型机器的真实游戏验收语料.

## 暂不支持

- 完整世界存档和区块 ticket.
- 随机刻, 流体, 火和爆炸世界修改.
- 世界生成, 生物 AI 和完整玩家物理.
- 多版本兼容层.
